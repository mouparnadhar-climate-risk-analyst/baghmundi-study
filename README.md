# Evaluating Public Service Delivery in Rural India 🇮🇳
### An Importance-Performance Based Assessment of Pivotal Government Schemes
**Location:** Baghmundi Block, Puruliya, West Bengal  
**Researcher:** Mouparna Dhar (University of Calcutta)

---

## 📊 Project Overview
This project is a digital representation of my post-graduate dissertation. It provides a granular, data-driven assessment of how effectively central and state government schemes are implemented at the Grassroots (Gram Panchayat) level in the Baghmundi Block.

Rather than providing broad audits, this study employs **Importance-Performance Analysis (IPA)** to help local administrators (BDOs and Panchayat Pradhans) identify exactly where implementation bottlenecks exist and which areas require the most urgent intervention.

## 🛠 Methodology
The study utilises a two-tiered analytical design based on secondary administrative data:
1. **Min-Max Scaling:** All raw units (monetary, percentages, and raw counts) were normalised onto a uniform 1-to-5 scale.
2. **IPA Matrix:** Plotting "Structural Importance" against "Operational Performance" across four quadrants:
   - *Keep Up the Good Work* (High Importance, High Performance)
   - *Concentrate Here* (High Importance, Low Performance)
   - *Low Priority* (Low Importance, Low Performance)
   - *Possible Overkill* (Low Importance, High Performance)
3. **Weighted Improvement Index (II):** A formulaic approach to prioritise intervention:  
   `II = (Importance - Performance) × Importance`

## 📋 Key Schemes Evaluated
The research covers the most pivotal developmental and social welfare programs:
*   **Livelihood:** MGNREGA (Employment Guarantee)
*   **Housing:** PMAY-G (Pradhan Mantri Awas Yojana - Gramin)
*   **Empowerment:** DAY-NRLM (Anandadhara - Self Help Groups)
*   **Income Support:** PM-KISAN (Direct Benefit Transfer for Farmers)
*   **Social Security:** NSAP (Old Age and Widow Pensions)
*   **Infrastructure:** PMGSY (Rural Road Connectivity) & Marble Lake Water Project

## 🚀 Interactive Dashboard Features
*   **Dynamic IPA Charts:** Switch between different schemes to see real-time shifts in the performance matrix.
*   **Priority GP Identification:** The dashboard automatically highlights which Gram Panchayat (like Matha or Tunturisuisa) is the highest priority for the selected scheme.
*   **Visual Insights:** Integrated research findings that explain the "why" behind the data.
*   **Mobile-Responsive Design:** Optimised for field use by local administrators.
